# Laugh & Learn Stories

A story app that makes you laugh and teaches you something wise.

- **For Teenagers** – school, friends, phones, growing up
- **For Everybody** – fables and tales for all ages

Pick a category, choose from a list of stories, and read each one on a background matched to its mood (forest, space, ocean, school, night...).

## Run it

No build needed. Open `index.html` in a browser, or:

```
python3 -m http.server 8000
```
